## 🎯 **Key Admin Actions**

### **Content Moderation**
```
Archive Post:
- Hides from public view
- Preserves data for review
- Reversible action
- Use for borderline content

Delete Post:
- Permanent removal
- Cannot be undone
- Use for spam/harmful content
- Removes all associated replies
```
