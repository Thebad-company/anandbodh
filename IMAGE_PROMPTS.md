## 📝 Notes for Image Generation

### Image Specifications:
- **Hero Images:** 1920x1080px (16:9 ratio)
- **Blog Headers:** 1200x630px (Open Graph)
- **Thumbnails:** 600x400px (3:2 ratio)
- **Icons:** 512x512px (1:1 ratio)
- **Profile Photos:** 400x400px (1:1 ratio)

### File Naming Convention:
- `hero-[page-name].jpg`
- `thumbnail-[content-name].jpg`
- `icon-[feature-name].svg` or `.png`
- `expert-[name].jpg`
- `blog-[slug]-hero.jpg`

### Optimization:
- Use WebP format for web
- Compress to 80-85% quality
- Provide 2x versions for retina displays
- Include alt text descriptions
