## 💡 KEY CONCEPTS

### On-Page SEO
- Optimizing individual pages for search engines
- Includes metadata, headings, content, links
- Directly under your control
- Immediate impact on rankings

### Metadata
- Title tag (50-60 characters)
- Meta description (150-160 characters)
- Keywords (comma-separated)
- Canonical tag (prevent duplicates)
- Open Graph tags (social sharing)

### Heading Hierarchy
- One H1 per page (main topic)
- Multiple H2s (major sections)
- Multiple H3s (subsections)
- Proper structure helps crawlers

### Internal Links
- Links to other pages on your site
- Use descriptive anchor text
- 3-5 per page recommended
- Help distribute page authority

### Structured Data
- JSON-LD schema markup
- Helps search engines understand content
- Enables rich snippets
- Improves click-through rate
